## 🌐 Project Overview
**Gridiron Edge** is a modern, interactive 3-page web application built from scratch to help fantasy football managers dominate their drafts, analyze player rankings, and evaluate trade offers. 

This project was built using HTML5 for structure, CSS3 for design and responsive layouts, and vanilla JavaScript for dynamic user interactivity and calculations.

---

## 🎨 Consistent Theme & Layout
The site features a cohesive dark-mode stadium theme across all pages:
- **Primary Colors:** Deep Navy (`#0f172a`), Stadium Green (`#16a34a`), and Trophy Gold (`#eab308`).
- **Typography:** Modern sans-serif stack (`Segoe UI`, `Verdana`).
- **Header & Navigation:** A persistent top menu bar present on every page with active link highlighting.

---

## 📄 Pages & Features

### 1. 📊 Player Rankings (`index.html`)
- **Consensus Rankings Table:** Displays top NFL fantasy players with projected points per game.
- **Live Search Bar:** Instant real-time player and team search filtering.
- **Position Filter:** Dropdown filter for QBs, RBs, WRs, and TEs.
- **Scoring Mode Switcher:** Interactive toggle button between **PPR Scoring** and **Standard Scoring**.

### 2. 📋 Draft Kit & Cheat Sheet (`draft.html`)
- **Draft Strategy Guide:** Round-by-round priority list and tier strategies.
- **Interactive Sleeper Notes:** Toggle button to show or hide secret late-round sleeper picks.
- **Positional Tier List:** Structured breakdown of player tiers.

### 3. 🔄 Interactive Trade Analyzer (`trade.html`)
- **Trade Value Calculator:** Select player packages for Team A and Team B.
- **Fairness Meter Bar:** Dynamic visual indicator calculating trade balance ratio.
- **Instant Result Feedback:** Displays edge alerts indicating which manager wins the deal.
